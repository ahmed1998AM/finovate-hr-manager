# Finovate HR Suite
## المكونات الرئيسية
- تسجيل دخول المستخدمين مع حساب مدير افتراضي.
- إنشاء حسابات موظفين من المدير وإدارة الصلاحيات (مدير/موظف).
- إدارة الموظفين وربط جميع العمليات بهم.
- الحضور والانصراف مع منع التكرار في نفس اليوم.
- إدارة المهام ومتابعة حالتها.
- إدارة العهد (تسليم/استلام).
- إدارة العمليات والطلبات (مثل السلف والطلبات الإدارية) مع الاعتماد.
- كشف رواتب شهري مرتبط بالغياب.
- لوحة تحكم بإحصائيات فورية.
- تصدير/استيراد البيانات JSON.
## الميزات
- إدارة الموظفين (إضافة/تعديل/حذف).
- تسجيل الحضور والانصراف مع منع التكرار لنفس اليوم (يتم التحديث بدل التكرار).
- إدارة الإجازات واعتماد الطلبات.
- لوحة ملخصات سريعة (عدد الموظفين، الأقسام، غياب الشهر، وعدد طلبات الإجازة).
- حساب كشف الرواتب الشهري حسب الغياب.
- حفظ البيانات تلقائيًا في LocalStorage.
- تصدير واستيراد البيانات بصيغة JSON.

## بيانات الدخول الافتراضية
- البريد: `admin@finovate.local`
- كلمة المرور: `admin123`

## التشغيل
افتح `index.html` مباشرة أو انشر المشروع على GitHub Pages.
=======
## النشر على GitHub Pages
1. ادفع الملفات إلى المستودع على GitHub.
2. من **Settings > Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (أو فرعك الحالي)
   - Folder: `/ (root)`
3. احفظ الإعدادات وانتظر رابط النشر.

## ملاحظات
- لا يحتاج Node.js أو قاعدة بيانات.
- البيانات محفوظة محليًا في متصفح المستخدم.
